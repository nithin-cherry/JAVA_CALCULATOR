This is a Java application that is a desktop calculator developed using Java Swing and AWT.
It has a simple graphical user interface that enables a user to perform basic arithmetic calculations like addition, subtraction, multiplication, division, percentage calculation, sign change, square root, and decimal calculations.

The application employs event-driven programming where every button is programmed to react to user input using ActionListener.

Key Components Used

JFrame → Main application window

JLabel → Display screen for numbers and results

JPanel → Separate panels for display and buttons

JButton → Calculator keys

Layout Managers

BorderLayout → Positions display at top and buttons in center

GridLayout (5×4) → Arranges calculator buttons uniformly

Top row (AC, +/-, %) 

Operators (+, −, ×, ÷, =) 

Number Input

Digits (0–9) append to the display

Leading zero is automatically replaced

Decimal point is restricted to one per number

A Java Swing-based calculator application featuring a modern UI, event-driven input handling, and support for common arithmetic and utility operations with clean number formatting.
