# JAVA_CALCULATOR
This was my first end-to-end Java project, where I developed a desktop calculator application using Java Swing and AWT.
The purpose of this project was to learn about GUI programming, event handling, and application logic in Java.

I used JFrame, JPanel, JButton, and JLabel to design the GUI and BorderLayout and GridLayout to lay out the components as closely as possible to a real-world calculator. I also developed a dark-themed GUI with color-coded buttons for better usability and readability.

In terms of functionality, my calculator supports basic math operations like addition, subtraction, multiplication, and division, as well as operations like percentage calculation, sign change (+/-), decimal point entry handling, and clear (C/AC). I handled user input using event-driven programming with ActionListener and tracked calculations using operands and operators.

To make the output more readable, I implemented logic to format the output by stripping off unnecessary trailing zeros. This project taught me about GUI component interaction with application logic, how to handle application state, and how to troubleshoot typical problems like string comparison and input validation.

This project gave me direct experience with Java Swing, layout managers, and event processing, and it provided a starting point for developing more complex applications.
